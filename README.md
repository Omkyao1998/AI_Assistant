# 🧠 AI_Assitant Your Personal Voice Assistant

AI_Assitant is a **voice-controlled AI assistant** built using **Python**, **OpenAI’s GPT models**, and **speech synthesis/recognition libraries**.  
It listens to your voice, understands your intent, generates intelligent context-aware responses, and replies back in a human-like voice with a hint of philosophical reflection — inspired by *Iron Man’s Jarvis* and *Hindu philosophy*.

---

## 🚀 Features

✅ **Voice Recognition:** Listens and converts speech to text using `speech_recognition`.  
✅ **Conversational AI:** Powered by **OpenAI GPT-3.5 Turbo** for human-like dialogue.  
✅ **Smart Context Detection:** Understands if your question is technical, philosophical, personal, or strategic.  
✅ **Voice Output:** Replies naturally using `pyttsx3` (text-to-speech).  
✅ **Utilities:** Can tell the current time, greet you, and respond to exit commands.  
✅ **Configurable & Extensible:** Add new commands or extend with APIs (e.g., weather, email, system control).
